Hook stdin payloads captured from Claude Code 2.1.311 (`claude -p --model claude-haiku-5-5 "say ok"`), with session ids, prompt ids and paths replaced by placeholders. No `Notification` fired in `-p` mode, so there is no fixture for it.

`codex-*.json`: Codex CLI 0.157.1 `codex exec` against a local stand-in model server, with per-run `-c hooks.<Event>=…` and `--dangerously-bypass-hook-trust`: the stdin of its `UserPromptSubmit`, `Stop` and `SessionEnd` hooks, and `codex-notify-arg.json`, the JSON a legacy `notify` command gets as its last argument (Jarvis doesn't use it). `opencode-events.jsonl`: plugin `event` payloads from OpenCode 1.18.31 `opencode run` the same way; its first 6 lines are captured, the rest (a subagent session, `permission.asked`, `question.asked`) are written by hand in the same shape. Ids, paths, models and the reply text are placeholders.

`agy-*.json`: Antigravity CLI (`agy`) 1.5.14, `agy -p` on `gemini-4-neon-low` with a `hooks.json` loaded from an `--add-dir` folder's `.agents/`: the stdin of its `PreInvocation` hook before a turn's first model call (`invocationNum` 0) and before the next one (`-next`, `invocationNum` 1), and of its `Stop` hook. agy writes them on one line; they're pretty-printed here, which also checks that the `invocationNum` match allows spaces. Ids, paths, the prompt and the added folder in `workspacePaths` are placeholders.
