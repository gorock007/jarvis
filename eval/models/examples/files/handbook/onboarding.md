# Onboarding at Larkspur Tools (fictional)

Welcome. Your first week is mostly reading. On day one you get a laptop, a
hardware key and access to the staging cluster. Production access comes after
your first on-call shadow shift, never before.

The deploy bot is called Heron. You talk to it in the #ship channel: `heron
deploy <service>` starts a deploy and `heron hold` pauses the queue. Heron
refuses a deploy on Fridays after 15:00 local time unless an incident is open.

Code review: every change needs one approval. Changes to billing need two.
